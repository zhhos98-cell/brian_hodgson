# Lepcha translation reserve as a collection-level paper layout program

Date: 2026-08-31

Status: paper-centred source-control note based on the later `List of Lepcha Manuscripts of the Hodgson Collection preserved at the India Office Library, London` contained in the uploaded René de Nebesky-Wojkowitz papers. This source is a later descriptive witness, not a substitute for direct codicological inspection of the Hodgson Lepcha manuscripts.

## Core result

The Lepcha blank-space case is stronger than a single manuscript example.

The later India Office-oriented list states that the Lepcha books in the library are **all, possibly with one exception, copies prepared for Brian Hodgson with a view to future translation**. It identifies the material sign of that purpose as:

- empty space on the **right side** of the Lepcha text;
- Nepalese translation already inserted in some places.

The secure collection-level sequence is therefore:

`commission copy -> allocate bilingual page geometry -> inscribe Lepcha text -> preserve right-side blank reserve -> later translation inserted selectively`.

Primary mechanisms:

- `COLLECTION_LEVEL_TRANSLATION_RESERVE`
- `PAPER_LAYOUT_AS_PROJECT_SPECIFICATION`
- `BLANK_SPACE_AS_SCHEDULED_LABOUR_CAPACITY`
- `COPY_PRODUCTION_FOR_FUTURE_OPERATION`

## 1. The paper layout precedes the translation

The important historical order is not:

`existing manuscript -> later reader happens to use spare margin for translation`.

The source describes the copies as **prepared with the view of future translation**.

Therefore the blank area is part of the copying brief.

Operation:

`anticipated translation -> page space reserved in advance -> copying executed around that reserve`.

Paper geometry is thus prospective. It encodes an operation that has not yet occurred.

## 2. Blank paper is labour capacity, not absence

The right-side blank zone is materially empty but operationally assigned.

It is better described as:

`scheduled but unperformed inscription space`.

Mechanism:

`BLANK_SPACE_AS_SCHEDULED_LABOUR_CAPACITY`.

This is more precise than generic language of `potentiality` because the later description gives the intended task: translation.

The paper surface contains two temporal states at once:

- present Lepcha inscription;
- reserved location for future Nepalese translation.

## 3. Partial translation makes the intended function visible

The same source says Nepalese translation has already been inserted `here and there`.

This provides internal confirmation of the proposed layout function:

`blank reserve -> selectively occupied by translation`.

A fully blank right-hand zone and a partially filled zone are therefore different workflow states of the same page architecture.

Possible state ontology:

- `TRANSLATION_RESERVE_EMPTY`
- `TRANSLATION_RESERVE_PARTIALLY_FILLED`
- `TRANSLATION_RESERVE_FILLED`
- `RESERVE_FUNCTION_UNVERIFIED` when direct page inspection is unavailable.

## 4. The collection was made as a future-work corpus

The source's wording — `all, possibly with one exception` — shifts the argument from one object to a copying programme.

The secure claim is not merely:

`one Lepcha manuscript has blank translation space`.

It is:

**the surviving India Office Lepcha collection was described as a corpus of commissioned copies whose page architecture was systematically prepared for a later translation operation.**

Mechanism:

`CORPUS_DESIGNED_FOR_DEFERRED_TRANSFORMATION`.

This is a strong paper-history example because copying does not simply reproduce an existing text. It redesigns the paper object for a new workflow.

## 5. Copying changes the object before any semantic translation occurs

Even if the Lepcha wording is copied faithfully, the new paper witness differs operationally from its exemplar because it contains a new spatial programme.

Sequence:

`source text -> commissioned copy with altered page allocation -> translation-ready witness`.

Mechanism:

`COPY_AS_LAYOUT_REENGINEERING`.

This reinforces the paper article's broader claim that copy state is not semantic duplication alone.

A copy can introduce:

- new blank zones;
- new writing direction or column relations;
- new future-use capacity;
- new bindings/wrappers;
- new identifiers.

## 6. Handwriting variation shows the programme exceeded one copyist

The later list says the books were written by **at least two different persons**, judged from handwriting.

It also distinguishes books written or dictated by a `bong thing` or `mun` — priests/priestesses of the Lepcha religion — whose hand is described as difficult and containing numerous orthographic errors.

Paper-centred implication:

The standardized future-translation layout should not be equated with one standardized hand.

Potential structure:

`shared page programme + multiple scribal hands + differentiated source/dictation roles`.

Mechanism:

`LAYOUT_STANDARDIZATION_WITH_HAND_VARIABILITY`.

The material template can remain stable while inscription labour varies.

## 7. Do not collapse copying, dictation and translation

The source distinguishes several operations that need separate fields:

- Lepcha text copied;
- Lepcha text possibly dictated by a ritual specialist;
- page space reserved for translation;
- Nepalese translation inserted later in some places;
- later twentieth-century cataloguer/transcriber describes the corpus.

Do not write a single undifferentiated chain of `informant -> translation`.

Paper allows these operations to coexist on one page while remaining spatially distinguishable.

## 8. This is not evidence that every blank leaf is a translation reserve

The evidence is unusually strong here because the source explicitly links right-side empty space to future translation.

General rule:

`blank space + explicit intended operation = designed reserve`.

By contrast:

- terminal blank leaves;
- interstitial blanks;
- unused notebook pages;
- binding stripes;
- margins

must not inherit this interpretation without independent evidence.

This preserves the existing repo distinction among blank-space functions.

## 9. Direct object tests

The strongest next operation is page-level inspection across a sample large enough to test the later description.

For each Lepcha copy record:

- shelfmark / manuscript number;
- page/folio;
- total page width;
- Lepcha text-zone width;
- right-side reserve width;
- ruling or guide marks;
- whether reserve is empty / partly filled / filled;
- language and hand of later translation;
- whether translation aligns line-by-line or block-by-block with Lepcha text;
- whether the same reserve proportion recurs across different copyist hands;
- paper type/support;
- sheet/leaf dimensions;
- folds, binding and trimming that may have altered the apparent reserve.

Do not infer physical measurements from OCR crop coordinates.

## 10. Falsification targets

The collection-level interpretation would weaken if direct inspection showed that:

- blank right-side space occurs only in a small minority of manuscripts;
- the empty area results from later cropping/binding rather than original copying;
- Nepalese translation is not spatially associated with the reserve;
- different manuscripts use unrelated layouts with no recurring translation-ready architecture.

The later list is therefore a strong hypothesis-generating witness whose claim should be tested against original pages.

## 11. Article-level formulation

**Hodgson's Lepcha copies were not simply reproductions of local texts. A later description of the India Office collection states that virtually all were prepared for him with future translation in view: the Lepcha text occupied one portion of the page while the right side was deliberately left empty, and Nepalese translation had already entered that reserve in places. The copy was therefore redesigned as a translation-ready paper object. Blankness here was not unused substrate but scheduled labour capacity, distributed across a corpus made for deferred transformation.**

## Bottom line

The Lepcha case is a collection-scale paper technology. Hodgson's copies were described as being made for translation before translation occurred, with page space intentionally withheld from the first inscription so that a second linguistic layer could later be added. Copying therefore produced not only another textual witness but a materially redesigned, translation-ready working object.
